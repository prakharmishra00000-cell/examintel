MASTER BUILD PROMPT
Build a Production-Ready AI-Powered Competitive Exam Intelligence & Preparation Platform
Build a production-ready, modern AI SaaS platform specifically designed for competitive-exam aspirants preparing for technical and non-technical examinations.
The platform must NOT feel like a generic AI chatbot, generic LMS, generic question bank, or simple study planner.
It should feel like an AI Exam Intelligence System that can:
Research exams
Understand official exam notifications
Compare multiple exams
Map common and exam-specific syllabi
Build prerequisite/dependency graphs
Detect knowledge gaps
Analyse official PDFs
Answer questions from documents
Explain questions at multiple levels
Transform existing questions into new practice questions
Generate personalized question papers
Generate PDF-grounded MCQs
Create adaptive preparation plans
Optimize preparation across multiple exams
Simulate preparation journeys
Analyse performance
Dynamically replan preparation
The central product principle is:
Give me an exam, syllabus, question, question paper, or PDF — and turn it into actionable preparation intelligence.
The overall experience should follow:
Research → Understand → Map → Compare → Diagnose → Practice → Generate → Prepare → Simulate → Analyse → Adapt

17. QUESTION EVOLUTION LEVELS
For every source question, generate up to five evolution levels.
LEVEL 1 — SAME CONCEPT, EASIER
Keep the underlying concept the same but simplify:
Numbers
Language
Reasoning complexity
Calculation
Number of steps
Purpose:
Build conceptual confidence.

LEVEL 2 — SAME CONCEPT, DIFFERENT FRAMING
Keep the same core concept but change:
Scenario
Wording
Question structure
Context
Data presentation
Purpose:
Ensure the student understands the concept rather than memorizing the original question.

LEVEL 3 — MULTI-CONCEPT
Combine the original concept with another related concept.
Example:
Percentage + Ratio
or:
Integration + Differential Equations
Purpose:
Test concept integration.

LEVEL 4 — DIFFICULT VARIANT
Increase:
Complexity
Number of steps
Distractor quality
Calculation difficulty
Conceptual depth
Purpose:
Prepare students for difficult questions.

LEVEL 5 — EXAM-TRAP VARIANT
Create a legitimate difficult question designed around common misconceptions.
Examples:
Similar-looking formulas
Unit traps
Sign errors
Logical traps
Close answer choices
Misleading wording
Do not create ambiguous or invalid questions merely to make them difficult.
